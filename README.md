**SmartScan EduPad** is an innovative electronic assessment system designed to automate the evaluation of handwritten answer sheets using image processing. Developed as a **B.Tech Final Year Project**, this system provides real-time scoring, detailed analytics, and comprehensive reporting for educational institutions.

**Experience the live application:**

## ✨ Key Features

### 📤 **Upload & Processing**
- **Multi-file Upload**: Upload multiple answer sheets simultaneously
- **Image Processing**: Automatic scanning and analysis using PIL
- **Batch Processing**: Evaluate entire class answer sheets in one go

### 📊 **Evaluation & Results**
- **Real-time Scoring**: Instant evaluation with percentage calculation
- **Grade Assignment**: Automatic grade assignment (A, B, C, D, F)
- **Pass/Fail Status**: Clear visual indicators for performance
- **Detailed Reports**: Comprehensive student-wise breakdown

### 📈 **Analytics Dashboard**
- **Interactive Charts**: Bar charts, pie charts, histograms using Plotly
- **Performance Metrics**: Average, highest, lowest scores
- **Grade Distribution**: Visual representation of class performance
- **Statistical Analysis**: Pass rate and performance trends

### 💾 **Data Management**
- **CSV Export**: Download results in CSV format
- **Session Management**: Preserve evaluation results
- **Data Tables**: Organized tabular display with sorting
